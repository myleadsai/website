# Contexto del proyecto: Myleads.ai

## Qué es
Web y material de marketing de Myleads.ai (socios: Franco y Tomás).
**Oferta actual:** sistemas integrales a medida para pymes. Centralizamos la información de la empresa (stock, pedidos, facturación, cobranzas, reportes, comunicación interna) en un solo sistema y automatizamos las tareas repetitivas.
**Frase de posicionamiento:** "Sistemas integrales a medida. Primero entendemos tu dolor, después construimos la solución."
**Proceso de venta:** diagnóstico de procesos → propuesta con números (si no le cierra, no seguimos) → sistema a medida.
**CTA:** Calendly https://calendly.com/myleads-ia/30min

La oferta anterior (programa "Conocimiento Exitoso" para expertos) quedó descartada. No volver a usarla.

## Archivos
- `index.html`: la web (una sola página, HTML + CSS en línea, publicada en GitHub Pages desde `main`). Reutilizar sus clases y las variables de `:root`. No agregar colores sueltos.
- `analisis-completo.md`: análisis de negocio, competencia, pauta, medición y plan de 90 días.
- `sistema-videos.md`: sistema para crear videos (ficha previa obligatoria, tipos de video, checklist).
- `videos-comparacion.md`: guiones Serie A (ellos vs nosotros) y Serie B (dolor → sistema) + video madre.
- `grabacion-hoy.md`: 5 guiones listos para grabar y guía de grabación.
- `guiones-videos.md`: primeros 10 guiones (estilo Cubria / Hormozi / Iman Gadzhi).

## Reglas de comunicación
- Español rioplatense con voseo.
- Hablar como dueño de pyme, no como programador (nada de "API", "base de datos", "stack").
- Comparar con categorías de competencia (ERP enlatado, consultora, programador freelance, Excel), nunca con marcas.
- No inventar casos, testimonios, precios ni garantías. Si hacen falta, pedirlos al equipo.
